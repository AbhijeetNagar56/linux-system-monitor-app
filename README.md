# Linux-system-monitor

# how to use ?
**Clone the repo**
```
git clone https://github.com/AbhijeetNagar56/Linux-system-monitor.git
cd Linux-system-monitor
```

**bash**
```
chmod +x ./scripts/script.sh # or monitor.sh
./script.sh
```
